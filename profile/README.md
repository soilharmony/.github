## SoilHarmony - Towards a harmonised pan-European monitoring of soil health descriptors

Welcome at a co-creation space of the SoilHarmony Horizon Europe project.

🙋‍♀️ About the project

SoilHarmony is a Horizon Europe funded Research and Innovation Action (call topic [HORIZON-MISS-2025-05-SOIL-04](https://cordis.europa.eu/programme/id/HORIZON_HORIZON-MISS-2025-05-SOIL-04) 
and project number [101296615](https://doi.org/10.3030/101296615)). The project started 1 June 2026 and ends 30 november 2030.

SoilHamony supports the development of a harmonized framework for soil monitoring in the EU towards healthy soils.
It will do so by developing transfer functions (TF) and [pedotransfer functions](https://en.wikipedia.org/wiki/Pedotransfer_function) (PTF) 
to support the implementation of the [soil monitoring law](https://eur-lex.europa.eu/eli/dir/2025/2360/oj/eng) (SML) 
and the EU Carbon Removal and Carbon Farming (CRCF) Regulation.
These functions will allow converting data obtained using national methods for soil descriptors into those defined in the SML.

🙋‍♀️ About the SoilHarmony GitHub organisation

The <https://github.com/soilharmony> organisation provides a workspace for collaboration on GitHub repositories that will be developed during the project.
